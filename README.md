### 关于

2013 年开始工作，第一份工是把别人的需求拆成一条条测试用例。后来发现重复的事情太多，就开始写脚本；脚本越写越大，成了工具；工具被团队用起来，成了平台；再后来需要界面、需要服务、需要部署、需要把 AI 接进来 —— 于是就成了全栈。

所以严格来说，我不是「转行」过来的，是**一路把问题解决到今天**。

同一件事做了十三年：**让复杂的东西稳定地跑起来。**

---

### 轨迹

| 阶段 | 角色 | 沉淀下来的东西 |
| :---: | :--- | :--- |
| 01 | 功能测试工程师 | 需求拆解、用例设计、缺陷分析 —— 对业务保持怀疑与耐心 |
| 02 | 自动化测试工程师 | Selenium / Pytest、数据驱动、接口自动化，把重复劳动交给代码 |
| 03 | 测试开发工程师 | 测试平台与工具链、CI 集成、质量度量，为整个团队提效 |
| 04 | Python 开发工程师 | 服务端开发、异步任务、数据处理，从脚本走向工程 |
| 05 | 全栈开发工程师 | Vue 3 + FastAPI，前后端一把梭，独立交付完整产品 |
| 06 | AI Agent 开发 | LLM 应用、多 Agent 协作、RAG 与工具调用，真正进业务链路 |
