### 你好

2013 年入行，第一份工是把需求拆成一条条测试用例。后来嫌重复的事情太多，开始写脚本；脚本越写越大，成了工具；工具被团队用起来，成了平台；再后来需要界面、需要服务、需要部署、需要把 AI 接进来 —— 于是成了全栈。

所以我不是「转行」过来的，是**一路把问题解决到今天**：功能测试 → 自动化测试 → 测试开发 → Python 开发 → 全栈开发 → Agent 开发。

十三年其实只做一件事：**让复杂的东西稳定地跑起来。**

### 开源

> **[🍊 python-vue-grapefruit](https://github.com/LangJin/python-vue-grapefruit)**
> 基于 Vue 3 + FastAPI 的全栈中后台解决方案，Web 管理端、桌面端、移动端、官网四端同仓。

- **四端同仓**：`frontend`（Element Plus 中后台）/ `desktop`（Naive UI）/ `mobile`（uni-app）/ `www`（VitePress）
- **插件化后端**：数据库、Redis、日志、加密、队列、OSS、短信都是可插拔的 plugin
- **代码生成器**：一张表生成路由、服务、CRUD，少写重复代码
- **异步任务**：taskiq + Redis 的队列消费与定时调度，`docker compose` 一键起
- **双数据库**：PostgreSQL 16（pgvector）/ MySQL 8.0，通过 `DB_ENGINE` 切换

`Vue 3`　`FastAPI`　`Tortoise ORM`　`Pinia`　`uni-app`　`taskiq`　`Redis`　`Docker`
