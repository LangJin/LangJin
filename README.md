## 关于我

<table border="0">
<tr>
<td width="62%" valign="top">

2013 年开始工作，第一份工是把别人的需求拆成一条条测试用例。后来发现重复的事情太多，就开始写脚本；脚本越写越大，就成了工具；工具被团队用起来，就成了平台；再后来，需要前端界面、需要后端服务、需要部署、需要把 AI 接进来 —— 于是就成了全栈。

所以严格来说，我不是「转行」过来的，是**一路把问题解决到今天**。

- 🧪 **测试出身**：功能 → 自动化 → 测试开发，质量是刻在骨子里的习惯
- 💻 **全栈交付**：Vue 3 + Python，从需求、接口、前端到部署一个人走完
- 🛠️ **工具控**：凡是做第二遍的事，都想写成脚本或平台
- 🤖 **Agent 开发**：让 LLM 真正进入业务链路，而不是只停在 Demo
- ✍️ **持续输出**：B 站录视频，知乎写长文，都是给自己留的复盘
